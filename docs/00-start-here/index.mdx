This handbook explains the source in this repository: the public site, its
recruitment form, the Cloudflare Pages Function that receives applications,
and the D1 database that stores them.

It is written for developers who know HTML but are learning TypeScript, React,
Next.js, HTTP, serverless functions, and SQL. You can read it in order, or
follow a request from the browser to its database row.
