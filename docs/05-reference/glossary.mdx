---
title: Glossary
description: Plain-language meanings for web development terms used in this repository.
---

| Term | Meaning here |
| --- | --- |
| API | A defined way for one program to request data or an action from another; this site uses HTTP and JSON for recruitment. |
| App Router | Next.js routing system where folders and files under `src/app/` define pages and layouts. |
| Binding | A named resource provided to a Cloudflare Function; `DB` is the D1 database binding. |
| Build | Convert source code and content into deployable output. Here the static site output is `out/`. |
| Client component | A React component that can use browser state, effects, and event handlers; marked with `'use client'`. |
| D1 | Cloudflare's managed SQL database based on SQLite. |
| D1 migration | A numbered SQL change applied to a local or remote D1 database. |
| Environment variable | A named value supplied to a process or deployment at runtime/build time. A `NEXT_PUBLIC_` value can be exposed to browsers. |
| Function / Pages Function | Server-side code Cloudflare Pages runs for matching requests; the recruitment route is a Function. |
| HTTP | The request/response protocol used by browsers and the recruitment API. |
| JSON | A text format used to represent objects, arrays, strings, numbers, booleans, and null. |
| JSX | JavaScript syntax for describing React UI; it resembles HTML but is compiled and follows JavaScript expression rules. |
| Migration | A versioned, reviewable database schema or data change. |
| Origin | The scheme, hostname, and port identifying a web origin, such as `https://example.com`. |
| Prepared statement | SQL with placeholders whose values are bound separately, helping keep data out of SQL syntax. |
| Props | Values passed from a parent React component to a child component. |
| Repository dispatch | A GitHub event sent to another repository to trigger its workflow. |
| Static export | HTML and assets generated ahead of time and served as files rather than rendered by a running Next.js server. |
| TypeScript | JavaScript with compile-time type checking; its types do not automatically validate incoming network data. |
