The recruitment route is the only user-facing data-entry flow in this repository.
The browser asks the Function for configuration, collects an application, and
sends JSON to the same-origin `/api/recruitment` route. Cloudflare validates it
again and writes it to D1.

<Warning>
  Applications contain personal information. Do not use real applicant values
  in examples or screenshots. The public API has no read/list route for
  submitted applications.
</Warning>
